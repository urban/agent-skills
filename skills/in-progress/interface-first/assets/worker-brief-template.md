# Worker brief

Fill only the context needed for this bounded assignment. Send actual file paths and source links; do not send the whole library.

- **Goal and task:** operable outcome or precise source question; exact ticket and shared slice links where applicable.
- **Ownership:** writable files/capability or read-only role, exclusions, tracker claim owner, commit policy and isolated output location if needed. You are not alone in the codebase: preserve others' edits and accommodate concurrent changes.
- **Read:** project instructions, affected design-map entries, accepted target/review and selected playbook/principle paths. Follow only necessary deeper links.
- **Behavior boundary:** approved units/states, intended delta, existing interface, real versus simulated dependencies, relevant failures and settled decisions.
- **Completion and verification:** observable predicate, focused checks, necessary live evidence, project gates and inspection limits. Do not infer human acceptance from implementation success.
- **Return:** `PASS`, `ISSUES` or `BLOCKED`; artifact paths and concise findings, checks/evidence, simulation limits and remaining decisions. Do not dispatch more workers unless explicitly assigned that responsibility.

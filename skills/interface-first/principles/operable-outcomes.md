# Prefer an operable outcome

**Apply when:** shaping scope, splitting preparation or tasks, or choosing what becomes real next.

Choose a result the user can operate and evaluate within a short implementation, verification and feedback loop. Include the whole loop's cost. Separate real capability from simulation, and probe uncertainty that could invalidate the selected outcome early.

**Example:** replace supplied transcript text with real import output in the existing reader before building unrelated future attribution controls.

**Tradeoff:** the smallest code change may not deliver useful user value. Keep necessary integration and consequential recovery in scope; defer adjacent ambition. A required human decision marks a useful slice boundary.

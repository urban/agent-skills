# Match evidence to the decision

**Apply when:** selecting checks, captures, artifacts or delegated review scope.

Choose evidence that can expose a meaningful mistake in the claimed outcome. Keep a small refinement small, while honoring mandatory project gates and consequential consumer, keyboard, timing and recovery behavior. Link existing records rather than generating another document set. Carry the stated acceptance bar across handoffs; fresh agents preserve context capacity, not permission to add another gate. Reuse valid evidence for unchanged relevant code and conditions, and broaden only for a distinct new risk, requirement, or failure.

**Example:** a local spacing correction needs a matching comparison and relevant layout/consumer checks; it does not by itself justify rebuilding the entire design catalog or rerunning model inference.

**Tradeoff:** visual simplicity can hide shared impact. Broaden verification for actual risk or observed failures. Simulation cannot replace real backend/device evidence, and an inconclusive check is not a pass.
